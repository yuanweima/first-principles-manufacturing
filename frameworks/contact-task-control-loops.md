# 接触任务三层控制环

**论点**:臂内三层循环——伺服(kHz,驱动器)/运动控制(125–500Hz,厂商控制器)/任务层(≤几 Hz)。agent 隔着 MCP 慢两三个数量级,永远够不到力响应快环;但最慢的漂移环恰是它的地盘。四工兵(检测/磨削/去毛刺/焊接)里接触三件的自动化边界由此决定。
