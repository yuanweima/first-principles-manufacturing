# 轴是可动的：把工序拖进可自动化的角落

**论点**：T01 地图的两根轴——失败代价 × 验证成本——是成本，不是工序的物理属性，成本可以被工程。往左拖 = 把失败变可逆（仿真 / 空跑 / 单步 / 低速的楼梯，每级台阶上的失败比下一级便宜）；往下拖 = 把验证变便宜（在工序后挂一道**独立于建造者**的检测，验证成本变成一帧图像）。每工程一项，工位就往自动化已跑得动的区域挪一步，不必等更聪明的机器人。落点不在 demo 角落——公差与漂移分布不变——而在机床上下料附近。
